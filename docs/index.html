Replay

Files open in your browser and are never uploaded. Any WACZ or WARC works, including ones made with other web-archive tools. Try a demo.

Save

Give it a URL and it visits the whole site on its own — links, sitemap, and the menu buttons of single-page apps — in a real browser, so JavaScript-heavy sites come out right. Runs on your computer; needs Python 3.9+ and pipx.

1. Install once (no pipx? brew install pipx or python3 -m pip install --user pipx, then pipx ensurepath)
pipx install git+https://github.com/duskarb/savveb
2. Save your site — you get one .wacz file
savveb save https://your-site.example/
3. Drop the file above, or replay it offline
savveb play your-site.example-2026-01-01.wacz

To link to an archive you've published, add ?source= and the .wacz URL to this page's address.
